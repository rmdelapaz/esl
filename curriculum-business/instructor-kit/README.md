# Business English — Instructor Kit ("Course-in-a-Box")

A ready-to-teach package that lets an adult-education, community, or workplace ESL teacher run
**Business English** as a live class. The free online course
(rays-esl.netlify.app/curriculum-business/) is the learners' homework and review — every lesson has 🔊 Listen buttons.

**Complete — all four modules are built.** For B1+ working adults (mixed B1–C1 classes): employees who use English at work, job seekers, and newcomers rebuilding a professional career. All companies, people, products, and figures in the materials are fictional.

|--------|---------|---------|--------|
| — Orientation + Needs Analysis & Diagnostic | — | C1 | ✅ Built |
| 1 · Professional Communication Foundations | 1.1–1.3 | C2–C4 | ✅ Built |
| 2 · Meetings & Interpersonal Skills | 2.1–2.3 | C5–C7 | ✅ Built |
| — Midpoint Performance Check (timed writing + call and meeting simulations) | — | C8 | ✅ Built |
| 3 · Presenting, Negotiating & Persuading | 3.1–3.3 | C9–C11 | ✅ Built |
| 4 · Business Writing & Career | 4.1–4.3 | C12–C14 | ✅ Built |
| — Final Assessment A (timed writing + negotiations) and B (capstone presentations + mock interviews) | — | C15–C16 | ✅ Built |

**Format:** 8 weeks · 2 classes a week · 90 minutes (16 classes, 24 hours). Every lesson class is a communication-skills
workshop: lead-in linked to learners' needs → model (email, dialogue, pitch) → notice and clarify the language (register,
CCQs) → drill key phrases (stress, intonation, polite tone) → controlled practice → role-play or simulation with A/B cards →
feedback on register, tone and clarity, with delayed error correction. C1 records each learner's workplace needs and starting
scores; C8 and C15–C16 are scored with the **same four-criterion rubric** (Task & Purpose · Register & Tone · Language Range &
Accuracy · Organization & Delivery, 1–5 each, /20), so progress is visible on each learner's performance tracker.

**Privacy by design:** learners are never asked to disclose salary, employment status, immigration status, or a real employer.
Every personal or work-history task offers a **role card** (a fictional job and company) instead.

## How to teach from it

1. **Before the term:** place learners with the toolkit's placement test (Business English works best from B1).
   Print the learner-welcome handout, one performance tracker per learner, and the Module 1 materials.
2. **Before each class:** read that class in the **teacher's guide** (stage plan = 90 minutes), print the
   module's **classroom materials** once, and open the module's **slide deck**.
3. **In class:** follow the stage plan. Learners write in the **student workbook**; give ICQs before every pair or group task.
4. **Homework:** the matching online lesson (URL in each class plan) — learners can hear every model sentence.
5. **Check:** the **answer key**; the C1 needs analysis, C8 performance check and C15–C16 final assessment,
   all scored with the rubric in the **assessment key**; each learner's **performance tracker**.

| Week | First class | Second class |
|------|-------------|--------------|
| 1 | C1 Orientation + Needs Analysis & Diagnostic | C2 Lesson 1.1 Register, tone & first impressions |
| 2 | C3 Lesson 1.2 Emails & messaging | C4 Lesson 1.3 Telephoning & virtual calls |
| 3 | C5 Lesson 2.1 Meetings | C6 Lesson 2.2 Small talk & networking |
| 4 | C7 Lesson 2.3 Diplomatic & assertive communication | C8 Midpoint Performance Check |
| 5 | C9 Lesson 3.1 Presentations | C10 Lesson 3.2 Negotiations |
| 6 | C11 Lesson 3.3 Pitching & objections | C12 Lesson 4.1 Reports & proposals |
| 7 | C13 Lesson 4.2 CVs, cover letters & interviews | C14 Lesson 4.3 Review project (plan + rehearse the capstone) |
| 8 | C15 Final Assessment, part A | C16 Final Assessment, part B + certificates |

Lesson file = `lesson_NN.html` (1.1 → 01 … 4.3 → 12). The Module 1 guide also plans C1; the Module 2 guide also plans C8
(and how to return results in C9's warmer); the Module 4 guide also plans C15–C16.

```
├─ student-workbook / teacher-guide / answer-key   (.html + .pdf)  ← the three books
├─ learner-welcome / sell-sheet                     (.html + .pdf)
├─ assessment/   needs-analysis · performance-check · final-assessment · assessment-key   (.html + .pdf)

├─ slides/       module-1-foundations.html … module-4-writing-career.html
├─ materials/    module-1/ … module-4/  classroom-materials.html
├─ source/       module-1/ … module-4/  — editable per-module docs (build the books)
├─ assets/vocab/ 154 illustrations
├─ kit.css       shared print-first stylesheet (with the course's ESL components)
├─ build-combined.py
└─ README.md · LICENSE.md
```

Every document has a **Print / Save as PDF** button and a tuned print layout (the learner welcome prints on two pages;
the sell sheet and performance tracker on one); decks are single files (arrow keys / space to advance) and need no
internet except for web fonts.

**Still to do:** `LICENSE.md` is a plain-language template — have it reviewed before commercial use.
Sell-sheet prices are `[$ ___ ]` placeholders. The rubric is a classroom tool, not a standardized test: for WIOA
reporting, use your program's NRS-approved assessment alongside it.
