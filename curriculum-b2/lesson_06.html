🔁 Lesson 2.3: Used to / Be Used to / Get Used to

Three structures, one little word — used to — and endless confusion. They look almost identical, but they mean completely different things: a past habit, a state of familiarity, and the process of adapting. Get them straight in this lesson and you'll never trip over them again.

📚 What You'll Learn

By the end of this lesson, you will be able to:

  • Use used to + base verb for past habits and states that are no longer true
  • Use be used to + noun / -ing to say something is familiar or normal for you
  • Use get used to + noun / -ing for the process of becoming familiar with something
  • Tell the three structures apart reliably — and spot the trap that catches almost everyone

⏱️ Estimated Time: ~55 minutes

🎯 Project: Talk (or record) for two minutes about a big change in your life — a new country, job, or routine — using all three used to structures naturally.

One Word, Three Meanings

Read these three sentences aloud. They share the words used to, yet each says something entirely different:

1. "I used to live in Madrid." → I lived there in the past, but not now. (a past habit/state)

2. "I'm used to living in a big city." → Big-city life is normal for me now; it doesn't bother me. (familiarity)

3. "I'm getting used to living abroad." → It was strange at first, but I'm slowly adapting. (the process of adapting)

The whole point of this lesson is to keep these three apart. The good news: once you see the underlying logic — past vs now (a state) vs changing (a process) — they stop feeling like a trap and start feeling like three precise tools.

🧠 Mindset

If you've mixed these up before, you're in excellent company — even advanced learners hesitate over them. Confusion here isn't a sign you're bad at English; it's a sign you're working at exactly the edge where real precision lives. Notice the mistake, smile, correct it, and move on. That loop — notice, correct, repeat — is how the three structures become automatic. 🌱

Used to + Base Verb

You met this one at B1. Used to + base verb describes a past habit or a past state that isn't true any more. It exists only in the past — there is no present form.

"I used to smoke, but I quit last year." (past habit — gone now)

"There used to be a bakery on this corner." (past state — gone now)

FormStructureExample
Positiveused to + base verbShe used to play tennis.
Negativedidn't use to + base verbHe didn't use to like coffee.
QuestionDid … use to + base verb?Did you use to live here?

💡 Spelling in the negative and question

Notice the d disappears: after did, it becomes use to, not used to — "Did you use to smoke?" / "I didn't use to smoke." (In speech the two sound the same, so this trips people up in writing.) Both "didn't use to" and the more formal "never used to" are common.

⚠️ Important Note: This structure is only about the past. To talk about a present habit, use the present simple with an adverb: "I usually get up early," not "I use to get up early." ❌

Be Used to + Noun / -ing

Be used to means to be accustomed to something — it's familiar and normal for you, so it no longer feels strange or difficult. It describes a state, and it works in any tense: am / was / will be used to.

"I'm used to the noise now — I don't even notice it." (familiar now)

"She's used to working nights; she's done it for years." (familiar now)

"After a month, I was used to the early starts." (familiar in the past)

Followed by…Example
a nounI'm used to the cold.
a pronounThey're used to it.
a gerund (-ing)He's used to getting up early.

⚠️ The classic trap

After be used to, you need a noun or a gerund (-ing) — never a base verb.

"I'm used to work long hours." ❌
"I'm used to working long hours." ✅

Why? Because here the to is a preposition (like to in "look forward to"), and prepositions are followed by nouns or -ing forms — not by base verbs. More on this in the Key Contrast below.

Get Used to + Noun / -ing

Get used to describes the process of becoming accustomed — the change from strange to normal, happening over time. Where be used to is the finished state, get used to is the journey toward it. It also takes a noun or a gerund.

"At first the weather was awful, but I'm getting used to it." (adapting right now)

"It took me a while to get used to driving on the left." (adapted over time)

"You'll get used to the new system soon." (will adapt in the future)

Tense / formMeaningExample
am/is/are getting used toadapting now, in progressI'm getting used to the commute.
got used tocompleted the adaptationEventually she got used to it.
will get used towill adapt in futureYou'll get used to living alone.
take time to get used toemphasises the effortIt took months to get used to the food.

✅ Be used to vs Get used to

Same ending (+ noun / -ing), different verb — and that verb changes everything. Be = the state of already being familiar ("I am used to it"). Get = the change of becoming familiar ("I'm getting used to it"). If you can swap in "become," you want get.

The Key Contrast

This is the heart of the lesson. Hold these three side by side until the pattern is second nature:

💡 The One Thing to Remember

used to + BASE VERB = a PAST habit (gone now)
be used to + -ing / NOUN = FAMILIAR now (a state)
get used to + -ing / NOUN = BECOMING familiar (a change)

The trap: "used to" alone takes a base verb; "be/get used to" take -ing or a noun.

StructureMeaningTimeFollowed byExample
used topast habit / state, not true nowpast onlybase verbI used to swim every day.
be used tofamiliar, normal for youany tensenoun / -ingI'm used to swimming in cold water.
get used tobecoming familiar, adaptingany tensenoun / -ingI'm getting used to swimming at dawn.

⚠️ Why the "to" behaves differently

In "used to do," the to is part of the infinitive — so a base verb follows. In "be/get used to," the to is a preposition — so a noun or -ing follows. Test it: replace the verb with "it." "I'm used to it" works, so "I'm used to working" is right. "I used to it" is nonsense, so "I used to work" (base verb) is right.

In Conversation

Here are all three structures woven naturally into a real chat between an old friend, Ben, and Sofia, who has just moved abroad for a new job.

Ben: So, how's life in Tokyo? Big change from our little hometown!

Sofia: Huge! I used to complain that nothing ever happened back home — well, now something's always happening. I'm still not used to the crowds, though.

Ben: I remember you used to hate commuting even on our quiet buses. How are you coping with the trains?

Sofia: Honestly? I'm slowly getting used to being squashed like a sardine every morning. The first week I nearly cried, but now it's just… normal.

Ben: And the job? You used to work nine to five. That's over, I imagine.

Sofia: Completely. I've got used to working late — I'm used to eating dinner at ten now. What I still can't get used to is how quiet everyone is on the train. You could hear a pin drop!

Ben: Ha! Give it time. This time next year you'll be so used to it, you'll find us loud.

💡 Notice the mix

used to complain / used to hate / used to work = old habits, now gone (base verb). getting used to being / can't get used to = still adapting (-ing / noun). got used to working / used to eating / used to it = now familiar states (-ing / noun). One conversation, all three jobs done cleanly.

Practice & Project

🏋️ Exercise 1: Choose the structure

Objective: Decide whether each situation needs used to, be used to, or get used to. Write the whole phrase.

  1. When I was a child, I (have) long hair. (past habit, gone)
  2. Don't worry about the spicy food — you'll (it) after a few days. (adapting in future)
  3. She's a nurse, so she (see) blood — it doesn't shock her. (familiar now)
  4. It took me ages to (drive) on the right in France. (adapted over time)
  5. There (be) a cinema here, but they knocked it down. (past state, gone)
✅ Answer

1. used to have · 2. get used to it · 3. is / 's used to seeing · 4. get used to driving · 5. used to be

🏋️ Exercise 2: Base verb or -ing?

Objective: Put the verb in brackets into the correct form after the structure given.

  1. I used to (play) the piano when I was young.
  2. He's used to (work) under pressure.
  3. We're getting used to (live) in a smaller flat.
  4. Did you use to (walk) to school?
  5. It was hard, but she got used to (get) up at 5 a.m.
✅ Answer

1. play (base — "used to") · 2. working (-ing — "be used to") · 3. living (-ing — "get used to") · 4. walk (base — "did … use to") · 5. getting (-ing — "get used to")

🏋️ Exercise 3: Correct the error

Objective: Each sentence uses used to with the wrong form or structure. Rewrite it correctly.

  1. I'm used to get up early these days.
  2. She didn't used to like her boss.
  3. It took me a month to get used to eat with chopsticks.
  4. I use to live in Paris ten years ago.
  5. Are you used to work at weekends now?
✅ Answer

1. I'm used to getting up early these days. (be used to + -ing) · 2. She didn't use to like her boss. (drop the d after didn't) · 3. It took me a month to get used to eating with chopsticks. (get used to + -ing) · 4. I used to live in Paris ten years ago. (past — keep the d) · 5. Are you used to working at weekends now? (be used to + -ing)

🎯 Your Project: Two Minutes on a Big Change

Speak out loud — to a partner, in a group, or into your phone's recorder. Your goal is a smooth two-minute talk about a major change in your life (moving country, starting a job, a new routine, becoming a parent) using all three structures.

  1. (3 min) Pick your change and jot down three "before" facts (used to), two things that are normal now (be used to), and one thing you're still adapting to (get used to).
  2. (3 min) Draft your talk in that order: how life used to be → what you're used to now → what you're still getting used to.
  3. (2 min) Say it out loud, aiming to use each structure at least once. Check every "be/get used to" is followed by a noun or -ing.
  4. (2 min) Solo: record it and listen back — did any "used to" grab the wrong form? Partner/group: swap talks and have your listener call out which of the three structures they heard.

Tips & Common Mistakes

✅ Do's

  • Use the "it" test: if "I'm used to it" makes sense, you're in be/get used to territory, so use a noun or -ing.
  • Reach for get used to whenever you could say "become accustomed to" — it signals change over time.
  • Remember be/get used to work in every tense: "I was used to it," "You'll get used to it."

❌ Common Mistakes

⚠️ Watch Out

  • Base verb after be/get used to: "I'm used to drive" ❌ → "I'm used to driving" ✅.
  • Keeping the d after "didn't": "I didn't used to smoke" ❌ → "I didn't use to smoke" ✅.
  • Confusing state and process: "I'm used to it" (already normal) vs "I'm getting used to it" (still adapting) — don't swap them.
  • Using "used to" for the present: "I use to jog every morning" ❌ → "I usually jog every morning" ✅.

📝 Lesson Summary

🎓 Key Takeaways

  • used to + base verb = a past habit or state that's no longer true ("I used to smoke"). Past only.
  • be used to + noun / -ing = accustomed, familiar, normal for you now ("I'm used to the noise"). Any tense.
  • get used to + noun / -ing = the process of becoming familiar, adapting over time ("I'm getting used to it"). Any tense.
  • The trap: "used to" alone takes a base verb; "be/get used to" take a noun or -ing, because there the to is a preposition.

🎉 What You've Accomplished

You've untangled one of English's most notorious look-alikes. You can now talk about how life used to be, what you're used to now, and what you're still getting used to — three precise ideas, cleanly separated. That's a genuine mark of an upper-intermediate speaker. 🎉

❓ Common Questions at This Stage

Is "I'm used to it" the same as "I used to do it"?

No — they're opposites in a way. "I used to do it" means you did it in the past but don't now. "I'm used to it" means it's familiar and normal for you now. Different word before it (am) and a different meaning entirely.

Can I always replace "get used to" with "be used to"?

Not without changing the meaning. Be used to = the finished state of familiarity. Get used to = the process of reaching it. "I'm used to the cold" (it's normal) is different from "I'm getting used to the cold" (still adapting). If you mean "becoming," you need get.

Why is it "used to working" but "used to work"?

It depends on the structure. In "be/get used to working," the to is a preposition, so a gerund follows. In "used to work" (past habit), the to is part of the infinitive, so a base verb follows. Same three letters, two grammatical jobs.
