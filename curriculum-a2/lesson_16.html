🔀 Lesson 6.1: First Conditional — Real Possibilities

Life is full of "if". If it rains, we'll stay home. If you study, you'll pass. These are real, everyday plans and choices. In this lesson you'll learn the first conditional — the natural way to link a condition to its result and talk about likely futures. It's simpler than it sounds, and you'll use it every day. 🌦️

📚 What You'll Learn

By the end of this lesson, you will be able to:

  • Form the first conditional: If + present simple, … will / might + base verb
  • Write both clause orders and use the comma in the right place
  • Choose will for a sure result and might for a possible one
  • Use conditionals for warnings, promises, plans, and cause → effect — and tell if from when

⏱️ Estimated Time: 45–55 minutes

🎯 Project: Make a personal "If… I'll…" plan for your week (or a decision you face) in 6+ sentences — spoken to a partner or recorded on your phone.

The World of "If"

You already know the present simple (it rains, you study) and the future with will and might from earlier lessons. The first conditional simply puts them together. It links a condition — something that may happen — to a result — what will happen because of it.

We use it all the time: "If I finish early, I'll call you." "If the shop is open, I'll buy some bread." "If you don't hurry, you'll miss the bus." Each sentence has an if part and a result part. When you can build both parts, you can plan, promise, warn, and make choices out loud. 🔑

🧠 Mindset

Don't think of this as a big new grammar mountain. Think of it as two things you already know, joined by "if". One half is the present simple; the other half is will/might. If the whole sentence feels long at first, that's normal — you just can't say it quickly… yet. Say it slowly, one half at a time. 🌱

The Form: Two Clauses

A first conditional sentence has two parts (clauses). Each one has a job:

  • The if-clause = the condition. It uses the present simple.
  • The result clause = what happens. It uses will or might + the base verb.

If it rains, we'll stay home. · If you study, you'll pass. · If I have time, I'll help you.

The most important rule is easy to remember: the if-clause uses the present, never will. The future word (will/might) lives only in the result.

If-clause (condition)Result clauseFull sentence
If it rainswe'll stay homeIf it rains, we'll stay home.
If you studyyou'll passIf you study, you'll pass.
If she callsI'll answerIf she calls, I'll answer.
If we leave nowwe won't be lateIf we leave now, we won't be late.
 
graph LR

    COND --> RES["will / might + base verb"]
    RES --> RESULT["the result"]

⚠️ Watch Out: no "will" in the if-clause

Use the present simple after if — not will. ✅ "If it rains, we'll stay home." · ❌ "If it will rain, we'll stay home." The word will belongs in the other half of the sentence, with the result.

Clause Order & the Comma

You can put the two clauses in either order. The meaning is exactly the same. The only change is the punctuation:

  • If-clause first → use a comma between the two parts.
  • Result first → no comma.
OrderComma?Example
If-clause firstYes ✅If you study, you'll pass.
Result firstNo ❌You'll pass if you study.
⚠️ Important Note: The comma is a written signal. When the sentence starts with if, we take a small breath in speech and write a comma. When if comes in the middle, there is no comma. Both sentences are equally correct.

If it rains, we'll take the bus. — We'll take the bus if it rains. · If I see her, I'll say hello. — I'll say hello if I see her.

will or might?

Both will and might can go in the result clause. They tell the listener how sure you are:

  • will = you are sure about the result. "If it rains, we'll stay home." (We definitely will.)
  • might = the result is only possible, not sure. "If it rains, we might stay home." (Maybe, maybe not.)
Result wordHow sure?Example
will / 'llSure resultIf you ask him, he'll help you.
won'tSure it won't happenIf we hurry, we won't be late.
mightPossible resultIf you ask him, he might help you.

💡 Same condition, different confidence

Notice that the if part doesn't change — only the result word does. "If I have time, I'll cook." (sure) vs "If I have time, I might cook." (maybe). Remember: after both will and might, use the base verb — help, cook, be — with no ending.

What We Use It For

The first conditional is a small tool with big jobs. Here are the everyday ones:

JobExample
WarningIf you touch that, you'll burn your hand!
PromiseIf you help me today, I'll help you tomorrow.
PlanIf the weather is nice, we'll go to the beach.
Cause → effectIf you heat ice, it melts. / If you don't water plants, they die.

Here's a phrase bank of useful openers. Mix and match them freely:

If I have time, … If it's sunny, … If you want, … If we're late, … … if you ask. … if I can.

Now let's hear two friends talk through a weekend decision:

A: Do you want to go hiking on Saturday?

B: Maybe. If the weather is good, I'll come with you.

A: And if it rains?

B: If it rains, we'll stay home and watch a film. But I might still come if it's just cloudy.

A: Good plan. If we leave early, we won't be tired at the top.

B: True. If you bring the map, I'll bring the snacks. Deal?

A: Deal! I'll text you on Friday night if the forecast changes. 🥾

✅ A Friendly Pattern

Did you notice how the friends kept trading if sentences? That's exactly how the first conditional works in real talk — one person's if answers another's. Once you have the shape, you can join any everyday plan or promise. 🎉

if vs when

Both if and when can start the condition, and both take the present simple. The difference is your certainty:

  • when = you are sure it happens. It's only a question of time. "When I get home, I'll call you." (I will get home — for sure.)
  • if = maybe it happens, maybe not. "If I get home early, I'll call you." (Maybe I will, maybe I won't.)

When the film ends, we'll go home. (It will end — sure.) · If the film is boring, we'll leave early. (Maybe it is, maybe not.)

💡 Quick check

Ask yourself: "Is this thing sure to happen?" If yes, you can use when. If it's only a possibility, use if. The rest of the sentence — present simple in the condition, will/might in the result — stays the same.

Tips & Common Mistakes

✅ Do's

  • Keep the present simple in the if-clause — the future word lives in the result.
  • Add a comma when the sentence starts with if; drop it when if comes second.
  • Choose will for a sure result and might for a possible one.
  • Use when for something certain and if for a possibility.

❌ Common Mistakes

⚠️ Watch Out

  • "If it will rain, …" ❌ → "If it rains, …" ✅ (no will in the if-clause).
  • "If you will study, you'll pass." ❌ → "If you study, you'll pass." ✅
  • "If it rains we'll stay home." ❌ (missing comma) → "If it rains, we'll stay home." ✅
  • "If I have time, I'll to help." ❌ → "If I have time, I'll help." ✅ (base verb after will, no extra to).

📝 Lesson Summary

🎓 Key Takeaways

  • Form: If + present simple, … will / might + base verb.
  • The if-clause uses the present — never will.
  • Either order works: comma when if is first, no comma when if is second.
  • will = sure result; might = possible result.
  • when = sure it happens; if = maybe. Use it for warnings, promises, plans, and cause → effect.

🎉 What You've Accomplished

You just learned to join a condition to a result — one of the most useful things you can do in English. Now you can warn a friend, make a promise, plan around the weather, and explain cause and effect. Every "if" sentence is a small map of the future: this happens, then that follows. That's a real A2 step up. 🎉

❓ Common Questions at This Stage

Why can't I say "If it will rain"?

In English, the if-clause carries the future meaning by itself, using the present simple. The word will would be doubling the future, so we keep it only in the result: "If it rains, we'll stay home." It feels strange at first, but it quickly becomes automatic.

Is there really no difference between the two clause orders?

The meaning is the same. The only difference is the comma: "If you study, you'll pass" (comma) and "You'll pass if you study" (no comma). Choose whichever sounds more natural in the moment — both are correct.

When should I use "might" instead of "will"?

Use might when the result is only possible, not certain: "If you ask him, he might help." Use will when you feel sure: "If you ask him, he'll help." The if-part stays exactly the same.
